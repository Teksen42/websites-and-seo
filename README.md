## What I did

For three websites, including [måløvkebab.dk](https://xn--mlvkebab-9za5q.dk) and [lagedor.dk](https://lagedor.dk), I took care of the technical side of getting them online and found on Google.

| Area | What I did |
| --- | --- |
| **Domains** | Set up the domains |
| **Hosting** | Hosted the sites and uploaded them |
| **Structured data** | Added schema markup, so search engines understand what each site is |
| **Sitemaps** | Made sitemaps, so search engines find every page |
| **Google Search Console** | Found pages with indexing errors and fixed them |
| **Keywords** | Looked at the top search queries to pick the right keywords |

## måløvkebab.dk

A paid web project I built alone in **HTML, CSS and JavaScript**: a menu card guests swipe through. The site shows the menu only, there is no ordering. I also set up the domain, the hosting and the SEO work above.

## lagedor.dk

I set up the hosting and did the SEO work above: structured data, sitemap and Google Search Console.
